## Live2D 缩放 & 拖拽修复

### Live2DView.vue 重写
- **缩放修复**：不再硬编码 scale=0.25。改为 `fitScale * userScale`：
  - `fitScale = min(容器宽/原生宽, 容器高/原生高) * 0.80` 先自适应容器
  - 再乘以 `live2dSettings.scale`（用户在设置页配置的值，默认 1.0）
- **拖拽模式**：新增 `dragMode` + `offsetX/offsetY`，支持自由拖拽调整模型位置
  - 位置偏移持久化到 `localStorage('live2dPosition')`
  - 提供 `setDragMode(val)` / `resetPosition()` 方法
- **设置联动**：监听 `window 'live2d-settings-changed'` 事件，设置变更时自动重载模型
- **Talking 动画**：实现 `startTalking()` / `stopTalking()`，周期性触发 Tap/Flick 动作（750ms 间隔）
- **自适应大小**：ResizeObserver 监听容器尺寸变化，自动调整渲染器和缩放
- **点击交互**：非拖拽模式下点击画布触发 Tap 动作
- 通过 `defineExpose` 暴露：`setDragMode`、`startTalking`、`stopTalking`、`resetPosition`

### ChatView.vue 修改
- live2d-header 新增两个圆形按钮：
  - ✋/📍：切换拖拽模式（toggleDragMode）
  - 🔄：重置位置（resetLive2DPosition）
- 拖拽模式激活时按钮高亮为渐变填充

### 修复的 CSS 语法错误

## 缩放按钮 + 设置页布局修复
